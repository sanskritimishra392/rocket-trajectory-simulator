# Rocket Trajectory Simulator

This project simulates rocket/projectile motion using Python.

## Features
- Planet selection (Earth, Moon, Mars)
- Animated rocket trajectory
- Physics-based projectile motion
- Graph visualization using Matplotlib

## Technologies Used
- Python
- NumPy
- Matplotlib

## Physics Concepts
- Projectile Motion
- Gravity
- Velocity Components

## Future Improvements
- Air resistance
- Fuel simulation
- 3D trajectory
- GUI interface
